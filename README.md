# Gerber Construction — website

The source for gerberconstructioninc.com. A static site: no framework. GitHub Pages hosts it: the workflow in `.github/workflows/pages.yml` runs `python3 site-src/build.py` on every push to `main` and publishes `dist/`. DNS stays in the Microsoft 365 admin center.

## What lives where

| | Where | Who |
|---|---|---|
| Words, project write-ups, contact details | `site-src/content.py` | Evan with Claude |
| Design, layout, page templates | `site-src/build.py` | Claude |
| Photos | `site-src/img/` (web-sized, committed); picks and crop options listed in `site-src/photos.txt`; originals stay in Dropbox `GCI Admin/Videos and Photos` at the paths in that file | Evan with Claude |
| Logos | `site-src/logo-green.png`, `site-src/logo-white.png` | brand files, don't edit |
| Published site | `dist/` (generated by the workflow; not committed) | generated by the build |

To add a photo: put the original in a folder named `<slug>.jpg`, add a line to `site-src/photos.txt` (optionally `| crop-bottom:22` to trim a date stamp), run `python3 site-src/make-web-images.py <folder>` (needs Pillow), commit the two files it writes to `site-src/img/`.

To change anything: edit `site-src/`, commit, push to `main`. GitHub rebuilds and republishes in about a minute. To preview locally, run `python3 site-src/build.py` from the repo root and open `dist/index.html`. The easiest way to do all of that is to ask Claude in the AI GCI project.

## Pages

One scrolling page, `index.html` (About, Services, Projects, Careers, Contact sections), and one page per featured project under `projects/`.

## Go-live checklist

1. **Pages.** Repo Settings → Pages → Source: GitHub Actions. Custom domain: `www.gerberconstructioninc.com`; Enforce HTTPS once the certificate is issued.
2. **Contact form.** Web3Forms access key for office@gerberconstructioninc.com goes in `SITE["form_key"]` in `site-src/content.py`. Until it is set, the form shows an email-us note.
3. **DNS (Microsoft 365 admin center → Domains → gerberconstructioninc.com → DNS records; Solution Innovators).** Replace the three Squarespace A records on `@` with GitHub's four: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153. Change the `www` CNAME from ext-cust.squarespace.com to `gerberconstruction1.github.io`. Nothing else changes: mail, Teams and Intune records stay as they are.
4. **Squarespace.** Cancel after the new site has been live for a week.
